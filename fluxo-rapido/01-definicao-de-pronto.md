# Definição de pronto

> Escreve 3 a 5 linhas antes de começar. Se tudo estiver marcado, a tarefa fecha. Cor, sombra e animação não entram aqui.

## Tarefa: Tela de login

- [x] O utilizador consegue entrar com email e palavra-passe
- [x] Erros aparecem em texto simples (credenciais inválidas, campo vazio)
- [x] Funciona no telemóvel
- [ ] Sessão mantém-se após recarregar a página

## Tarefa: Listagem de produtos

- [ ] Mostra nome, preço e imagem de cada produto
- [ ] Estado vazio mostra uma mensagem clara
- [ ] Carregamento mostra um indicador simples
- [ ] Funciona no telemóvel

## Tarefa: Carrinho

- [ ] Adicionar e remover produtos
- [ ] Total atualiza em tempo real
- [ ] Carrinho mantém-se ao recarregar
